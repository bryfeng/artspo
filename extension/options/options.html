Artspo setup

Where your library lives, how it's organized, and how your agent finds it.

  1. Pick where clips go (or keep the default).
  2. Name a few collections for the kinds of sites you save.
  3. Give your agent the skill, then clip your first site with Alt+Shift+S.

1Library folder

Every clip is saved as a folder in here, with a clip.md your agent reads.

Downloads /
Want it outside Downloads (Dropbox, iCloud, a projects folder)?

Chrome only lets extensions save inside your Downloads folder. To keep the library somewhere else, leave the name above as it is and link that spot to your real folder. In Terminal:

Change ~/Dropbox/artspo to where you want it. The link must not already exist as a real folder: move any clips into the new place first. On Windows: . Clip one page afterwards to check it lands where you expect.

2Collections

Each collection is a folder in your library: inbox, fintech-serious, playful-onboarding. The popup offers this list, and new clips go to the default.

    3Your agent

    Coding agents (Claude Code, Codex, Cursor, Gemini CLI, Copilot) learn Artspo from a skill. From the folder you installed Artspo from, run:

    sh install.sh

    No skill support? Nothing to install: the library carries its own instructions in AGENTS.md, written with your first clip. Point your agent at the library folder and start with "Read AGENTS.md first."

    4Inspection

    Clipping is instant. The full inspection (screenshots, measurements, motion) runs once you've been idle for:

    Saved

    Reconnect a library

    After reinstalling Artspo, moving the extension, or on a new computer: choose your library folder, and Artspo relearns your clips, notes and collections from the clip.md files. Set the library folder above first. Nothing on disk changes.
